+------------------+
| Function: main   |
+------------------+
| a = [???]        |

+------------------+

Step 2: f() returns, execution back in main

+------------------+
| Function: main   |
+------------------+

+------------------+



Step 3: main calls g()
+------------------+
| Function: main   |
+------------------+
| a = ()           |
+------------------+
| Function: g      |
+------------------+
| ret = ()         |
+------------------+

Step 4: g() returns, execution back in main

+------------------+
| Function: main   |
+------------------+
| a = ()           |
+------------------+

Key Difference from Program 1:
- Program 1: main → f → g (all three on stack simultaneously)
- Program 2: main → f (returns) → g (f and g never coexist on stack)
